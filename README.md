# Snake Game by DeepSeek in InfinityCode

My first vibe-coded HTML game, created with **DeepSeek V4 Pro** through **InfinityCode**.

This project was an experiment to prove that InfinityCode could take an idea and turn it into a working browser game through iterative prompting, coding, testing, and refinement.

## Built with

- HTML
- CSS
- JavaScript
- DeepSeek V4 Pro
- InfinityCode

## Run locally

No build step is required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Play.

If the game uses local assets or browser features that need a local server, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000
```

## About the experiment

This game is the first project built with InfinityCode as a real-world test of its workflow:

- describe an idea in plain language
- let the coding agent generate and revise files
- test the result in the browser
- keep iterating until the game works

It demonstrates that InfinityCode can be used for practical vibe-coding projects, not only experiments or code snippets.
